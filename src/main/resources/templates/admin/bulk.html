Bulk Status Update

Update multiple shipments at once for Express Corporation of India.

CSV Instructions

Provide one row per shipment using this format:

trackingId,status,location,remarks
ECI1000000001,IN_TRANSIT,Ahmedabad Hub,Departed origin
ECI1000000002,OUT_FOR_DELIVERY,Surat Branch,With courier
  • Header row is optional.
  • status must be an allowed next status for that shipment.
  • location is required; remarks is optional.
