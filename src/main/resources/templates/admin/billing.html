Billing

Rate setup

Submitting a manifest creates two bills: a party bill and a branch bill. Charge is billable kg × per kg. Set a default per kg for a party, then override it per destination city. Tag a party for a minimum rate if a short consignment should still be billed at a minimum kg. Example: ₹8 per kg and a 5 kg minimum — 3 kg is billed as 5 × 8 = ₹40, not ₹24.

Party rates by city

Use Party rates to pick a party, turn the minimum rate on or off, and set destination cities from Indore in one place. This section still saves a single city if you need a quick change. Pick a party, then set the per-kg rate for each destination city you bill. A city rate replaces the party default for consignments to that city. If the party is tagged, you can also set a minimum kg for that city. Leave minimum kg blank to use the party minimum.
